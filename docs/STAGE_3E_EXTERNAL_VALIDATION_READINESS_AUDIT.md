## 8. Blockers & Required Provisioning

### A. Security Blockers (Must Fix Before Any External Test Target Access)
- **SEC-1 (Critical):** `page.route('**/*', ...)` bypass via **WebSockets (`ws:`/`wss:`)** (`universal_form.js`, `browser_worker.js` — add `context.routeWebSocket` / `page.routeWebSocket` aborting non-allowlisted / non-WSS / blocked-IP targets).
- **SEC-2 (Critical):** `page.route` bypass via **Service Workers** (`browser_worker.js:172` — pass `serviceWorkers: 'block'` in `browser.newContext(...)` and move interception to `context.route(...)`).
- **SEC-3 (Critical):** `page.route` bypass via **popups / `window.open` / `target="_blank"`** (`browser_worker.js:176`, `universal_form.js:200` — install guard at `BrowserContext` level `context.route('**/*', ...)` and attach `context.on('page', ...)` failing closed on unexpected popup navigations).
- **SEC-4 (Critical):** **Zero DNS resolution & DNS-rebinding defense in worker** (`universal_form.js:52-71, 124-299` — resolve DNS safely in Node before Playwright `route.fetch(...)` and connect via pinned verified public IP or enforce custom Agent/resolver rejecting private/loopback/link-local/CGNAT/unique-local IPs at resolution & connect time for every request and redirect hop).
- **SEC-5 (High):** **Trailing-dot bypass & subresource arbitrary ports** (`universal_form.js:47-71, 160-167` — normalize/strip trailing `.` before host checks, enforce strict port policy (`80`/`443` or default `443` in prod) on subresources, fix `UniversalBrowserPlanService#isDedicatedAtsUrl` host check, and enforce `AddressGuard` on `AtsHandoffService.validateTargetUrl`).
- **SEC-6 (High):** **Unencrypted persistent browser `storage.json` session files & URL logging** (`browser_worker.js:172, 343`, `UniversalBrowserPlanService:240`, `ApplyController:169` — zero/delete `sessionDir/storage.json` on completion/failure/handoff or encrypt session state at rest, and sanitize `applicationUrl` before info logging / audit persistence).
- **SEC-7 (High):** **Missing application-URL domain binding in `EmployerCredentialController#resolve`** (`EmployerCredentialController.java:102-116` — look up `jobs.application_url` for `r.applicationId()` and require resolved host matches registered domain/parent policy before decrypting credentials).
- **SEC-8 (Medium):** **Missing `10 MiB` file-size cap & header stripping on cross-origin redirects** (`universal_form.js:245, 1110`, `worker.js:422` — enforce `MAX_UNIVERSAL_UPLOAD_BYTES = 10 * 1024 * 1024` matching Workday/Zoho/Ashby plus `%PDF-` / MIME validation, and strip `cookie`/`authorization` headers across cross-origin subresource redirects).
