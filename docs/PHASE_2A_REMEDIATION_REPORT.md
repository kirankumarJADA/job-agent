## 2. Detailed Findings Remediation

### 2.1 [P0-1] Concurrency & Lock Ownership
- **Problem in Baseline:** PostgreSQL session-level advisory locks (`SELECT pg_try_advisory_lock(?)`) were acquired through HikariCP pooled connections. Upon checkout completion, connections returned to the pool while still holding the physical lock. Unlocking in the `finally` block targeted a different connection, leaving orphaned locks and breaking mutual exclusion.
- **Remediation:**
  - Added `execution_owner_token UUID` and `execution_lease_expires_at TIMESTAMPTZ` to `search_plans` via [`V065__search_plans.sql`](file:///c:/Users/jadak/Documents/antigravity/peaceful-chandrasekhar/.claude/worktrees/remediation-discovery-hardening/backend/src/main/resources/db/migration/V065__search_plans.sql).
  - Implemented `SearchPlanRepository.claimExecutionLease(planId, ownerToken, leaseDurationMs)` using an atomic single-statement `UPDATE ... WHERE id = ? AND active = true AND (last_execution_status IS NULL OR last_execution_status <> 'RUNNING' OR execution_lease_expires_at IS NULL OR execution_lease_expires_at < now())`.
  - Implemented fencing via `completeExecution(planId, ownerToken, status, error, resultsCount)` requiring matching `execution_owner_token`, preventing expired workers from corrupting state.
  - Implemented `recoverStaleExecutions(Instant now)` to automatically recover abandoned leases.
- **Verification:** [`SearchPlanConcurrencyAndRecoveryIT.java`](file:///c:/Users/jadak/Documents/antigravity/peaceful-chandrasekhar/.claude/worktrees/remediation-discovery-hardening/backend/src/test/java/com/personal/jobagent/discovery/plan/SearchPlanConcurrencyAndRecoveryIT.java) (10 concurrent workers mutual exclusion, parallel execution of separate plans, fencing protection, stale recovery).

### 2.3 [P1-1] Disconnected Multi-Stage Reranker in Match Service
- **Problem in Baseline:** `JobMatchService.evaluateMatch()` invoked `multiStageReranker.rerank()`, but ignored its score and recommendation, persisting the legacy 1-stage weighted score to `job_matches.score` and emitting notifications based on the legacy decision. Disqualified jobs received `APPLY` recommendations if legacy scores were high.
- **Remediation:**
  - Updated [`JobMatchService.java`](file:///c:/Users/jadak/Documents/antigravity/peaceful-chandrasekhar/.claude/worktrees/remediation-discovery-hardening/backend/src/main/java/com/personal/jobagent/jobs/JobMatchService.java) to treat `MultiStageReranker` as authoritative.
  - Ineligible jobs (`!rerankResult.eligible()`) are strictly forced to `finalScore = 0` and `finalRecommendation = "SKIP"`.
  - Outbox notification emission is strictly gated by `finalRecommendation.equals("APPLY")`.
  - Notification payload contains `finalScore` and `finalRecommendation`.
- **Verification:** [`JobMatchServiceRankingPersistenceIT.java`](file:///c:/Users/jadak/Documents/antigravity/peaceful-chandrasekhar/.claude/worktrees/remediation-discovery-hardening/backend/src/test/java/com/personal/jobagent/jobs/JobMatchServiceRankingPersistenceIT.java) and [`JobMatchServiceTest.java`](file:///c:/Users/jadak/Documents/antigravity/peaceful-chandrasekhar/.claude/worktrees/remediation-discovery-hardening/backend/src/test/java/com/personal/jobagent/jobs/JobMatchServiceTest.java).

### 2.4 [P1-2] Unhandled Exceptions Trap Plans in RUNNING State
- **Problem in Baseline:** Runtime exceptions in `doExecute()` bypassed status recording and failed to update `last_run_at`. Search plans remained in `RUNNING` status permanently, triggering immediate 60-second retry storms from the scheduler.
- **Remediation:**
  - Wrapped coordinator execution in a comprehensive fail-safe block catching `Exception` (while intentionally allowing JVM-fatal `VirtualMachineError` / `Throwable` to bubble).
  - On exception, records `FAILED` status, serializes exception error details, and sets `last_run_at = now()`.
  - Releases the lease or applies token fencing to clean up cleanly.
  - Scheduler invokes `recoverStaleExecutions(Instant now)` on every sweep to automatically recover unhandled crashes.
- **Verification:** [`SearchPlanConcurrencyAndRecoveryIT.java`](file:///c:/Users/jadak/Documents/antigravity/peaceful-chandrasekhar/.claude/worktrees/remediation-discovery-hardening/backend/src/test/java/com/personal/jobagent/discovery/plan/SearchPlanConcurrencyAndRecoveryIT.java) and [`SearchPlanSchedulerTest.java`](file:///c:/Users/jadak/Documents/antigravity/peaceful-chandrasekhar/.claude/worktrees/remediation-discovery-hardening/backend/src/test/java/com/personal/jobagent/discovery/plan/SearchPlanSchedulerTest.java).
